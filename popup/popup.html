央国企网申速填

AI + 规则引擎，填表只留确认权给你

我的简历

    还没有简历，点击「新建」创建，或导入 JSON 文件

    支持多份简历：不同招聘网站可各自记忆使用哪份简历（在网页悬浮球中切换即记住）。

    设置

    省市区级联、自绘下拉这类组件会忽略程序合成的点击，只认真实输入。开启后插件通过调试协议发出可信事件来点中它们，代价是页面顶部出现一条「正在调试此浏览器」横幅（点它的「取消」会退回合成事件，不影响其它填写），且同一标签页开着 F12 时不可用。

    API Key 仅保存在本机浏览器，AI 请求由扩展后台直连你配置的服务。API 地址填到主机端口（如 http://1.2.3.4:3000）或带 /v1 均可，插件会自动补全 /v1 并兼容各类中转站。填写「解析服务地址」后，上传简历将走 LangGraph 智能体（DOCX 表格感知 + 逐板块结构化）。

    本地记录

    「记录职位」与「辅助填写-反馈不适配」的数据只保存在本机浏览器，可在此查看与导出；投递记录支持状态跟踪（已投递/笔试/面试/Offer/已结束）。

    使用方法

    1. 新建/导入简历并填写完整（信息越全，命中率越高）
    2. 打开任意招聘网申页面，浏览器右边框出现 速填悬浮球（只能沿边框上下滑动，横向吸附不会乱跑，高度会记住）
    3. 点击悬浮球 → 一键填写；只填某一段经历用 选区填写；个别填不进的字段用 辅助填写；复杂下拉用 AI 辅助点击
    4. 绿色=已填写，红色=缺失/未识别，请人工复核后再提交
