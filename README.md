# 央国企网申速填简历（Edge / Chrome 扩展）

自动识别招聘表单 → 语义匹配字段与简历信息 → 一键填写 → 高亮预览 + 缺失提醒。
规则引擎为主、可选 AI 语义增强；填写结果全部高亮标注，**最终确认与提交权始终在你**。

## 安装到 Edge

1. （首次克隆代码）准备非入库资源，在项目根目录执行：
   - 下载 PDF 本地解析库：`powershell -ExecutionPolicy Bypass -File scripts/fetch-pdfjs.ps1`（Windows）或 `bash scripts/fetch-pdfjs.sh`（macOS/Linux），产物落在 `lib/vendor/`（见 `lib/vendor/README.md`）；
   - 生成扩展图标与测试样例：`node scripts/make-icons.js`、`node scripts/make-sample-resume.js`、`node scripts/make-sample-pdf.js`。
   > 这些二进制文件（pdf.js、图标、样例 docx/pdf）体积较大或可由脚本确定性生成，因此不纳入版本库。
2. 打开 Edge，地址栏输入 `edge://extensions` 回车
3. 打开左下角「开发人员模式」
4. 点击「加载解压缩的扩展」，选择本目录
5. 安装完成，工具栏出现扩展图标

> Chrome 同理：`chrome://extensions` → 开发者模式 → 加载已解压的扩展程序。
> 修改代码后在 `edge://extensions` 页面点击扩展卡片上的「重新加载」即可生效。

## 使用流程

1. 准备简历，二选一：
   - 点击工具栏图标 → 「上传简历解析」，选择已有的 PDF / Word(.docx) / TXT 简历，插件自动解析为结构化简历并打开编辑器供你核对补充；
   - 或「+ 新建」手动填写（首次安装已内置一份示例简历，请替换为你的信息）。
2. 在编辑器按模块填写（**16 个板块、约 240 个字段**，与主流网申简历编辑器对齐）：基本信息 / 求职意向 / 教育经历 / **工作经历** / **实习经历** / **项目经历** / 校园经历 / **社会实践** / 证书 / 获奖经历 / 专利信息 / 论文发表 / 外语能力 / 技能特长 / 自我评价 / 家庭情况。每个字段下方有填写说明，左侧导航实时显示各板块完成度与「未补齐 N 项」。
3. 支持多份简历（如「国网一批-技术岗」「省考-综合岗」），支持 JSON 导入导出备份
4. 打开任意网页（北森、大易、智联、Moka、各单位自建表单，乃至普通网站），**永远常驻**的品牌蓝悬浮球吸附在浏览器**右边框**：横向锁死不会满屏乱跑，只能沿边框上下滑动避让页面内容，纵向位置记住、双击复位、被页面脚本误删会自动重建、窗口变小会自动回到可视区。安装或更新扩展后已打开的标签页会自动补注入，不必手动刷新
5. 点击悬浮球查看匹配预览（可填写 / 简历缺失 / 未识别 三类统计与字段清单），点击「一键填写」
6. 填写后：
   - 绿色实线 = 已填写（悬停可见来源字段与值）
   - 红色虚线 = 简历中缺该项，请补充简历或手填
   - 橙色虚线 = 未识别字段，请手动填写
   - 灰色虚线 = 选区填写时圈进来、但不属于你选中的那一组，已跳过（不是错误）
7. 人工复核无误后再提交表单（插件不会自动提交）

## 四种填写方式

悬浮球面板提供四种互补的填写方式（复刻「简历智能助手」式布局）：

- **一键填写**：读取本地简历 → 「理解页面」（拆解页面结构，寻找可填写区域）→ 「填写页面」（Agent 正在填写剩余字段，逐项写入）→ 再回到「理解页面」补扫新出现的区域，最多三轮，动态渲染的表单也能补上；完成后提示「✓ 简历填写完成」并可评价。全程只写空字段，**绝不覆盖你已输入的内容**。
- **选区填写**：解决 AI 未识别某段表单的情况。点击「选区填写」→ 在页面上**框选一组**经历（如一段工作经历）→ 在确认弹窗里选模块与记录（如「工作/实习经历 → 第 1 组-某公司」）→ 只把这一组记录填进圈内字段。
  > ⚠️ 一次只能框选**一组**：选区填写的原理是把选中的那组经历填进对应组件，框选两组会导致经历重复填写。若圈内有多个分组，请「重新框选」只保留一组。
- **辅助填写**：解决个别组件 AI 未识别的情况。点击「辅助填写」打开「简历闪填」面板（按模块列出全部简历字段）→ 点某个字段即复制其值 → 再点击网页上要填的输入框，值即自动写入（支持文本框 / 文本域 / 可编辑区 / 原生下拉 / element-ui、ant-design 自定义下拉与级联）；按 Esc 可退出待填状态。部分网站组件结构特殊可能不适配，此时可点面板底部「反馈不适配」提交该网站。
- **AI 辅助点击**：针对截图站那种多列级联、自定义下拉。有两种入口：一键填写里启发式点选失败后自动跑（需开启 AI 且未关闭「AI 辅助点击」）；或在悬浮面板单独点「AI 辅助点击」，先选简历字段再点页面控件。插件把当前可见选项发给模型，模型只返回下一步（点选项 / 点「完成选择」等），由页面脚本执行，最多 10 步。未配置 API Key 时自动跳过，仍走剪贴板兜底。

面板还提供：**记录职位**（保存当前职位名称/链接/备注到本机）、**管理投递**（查看、删除、导出这些记录）、**编辑简历**、**切换简历**（切换后本网站记住你的选择）、**隐藏闪电悬浮按钮**（隐藏后屏幕右缘出现迷你恢复入口，点击即恢复）。

### 交互与动效

全部 UI 动画只用 `transform`/`opacity`（合成器属性，不触发重排重绘，在别人的页面上常驻运行也不拖慢加载），并整体尊重系统的「减少动态效果」设置：

- 悬浮球：入场弹跳、外圈光环呼吸（替代旧版持续重绘阴影的做法）、贴边悬停时向左滑出 + 按压回弹，拖拽期间自动停用按压/呼吸避免视觉抖动。
- 面板与弹窗：从悬浮球方向展开/收起（scale+fade），遮罩淡入、对话框上浮；「识别统计与简历」按高度动画展开，箭头随开合旋转。
- 按钮：统一 hover/active 缩放反馈，主按钮悬停上浮；「一键填写」进行中显示加载转圈；键盘焦点有可见描边环。
- 统计数字变化时弹跳提示；辅助填写选中字段有确认动效；Toast 滑入滑出；进度条忙碌时有流光扫过。
- 面板为半透明磨砂玻璃质感（`backdrop-filter` 背景模糊 + 约 78% 白色底），能透出页面又不干扰阅读；不支持背景模糊的环境自动退回接近不透明。透明度由 `content/overlay.js` 顶部的 `--qf-glass` / `--qf-glass-tint` 两个变量控制。

## 字段覆盖范围

四期把简历数据模型扩到与主流网申简历编辑器同级，五期继续对齐结构差异（`lib/resume-schema.js` 元数据驱动，编辑器、匹配引擎、选区填写、辅助填写共用同一份定义）：

- **基本信息 59 项**：中英文姓名与拼音、证件类型/号码、国籍民族、户口性质与户口所在地、生源地、最高学历/学位/毕业院校/毕业专业、学习形式、是否应届生、工作状态、工作年限、上一家公司、英语等级、高考时间/分数/科目、专业技术职称、紧急联系人三项、健康状况、长期病史、犯罪记录、服兵役/退伍、血型、入团/入党时间、保研、留学经历、贫困生、色弱、境外身份、档案所在地、个人主页、个人优势、兴趣爱好、职业规划等。「现居城市」「入党时间」类表单项分别由「现居住地址」「入团/入党时间」取值。
- **求职意向 13 项**：目标岗位、期望/当前行业、期望与面试城市、期望月薪/年薪、当前薪资、到岗时间、是否有亲人在该公司、信息来源、是否接受调剂。
- **教育经历 每记录 41 项**：院系、专业类别、学校城市与类型、学历状态、学制、起止时间、学位类型/类别、教育方式、招生类别、是否统招、绩点、挂科数、班级/专业排名、专业人数、学历证书编号、学位证书编号、学号、导师姓名与联系方式、实验室、是否国家重点实验室、是否联合培养、辅导员姓名与联系方式、是否海外学校、教育/专业描述、专业课程、研究方向、毕业论文等。
- **工作经历 / 实习经历 各 17 项（两个独立板块）**：公司规模、是否海外、部门、职位、城市与行业、用工性质、月薪/年薪、证明人姓名·联系方式·职位、描述、离职原因。拆成两块是因为网申表单常同时出现「工作经历」和「实习经历」两张表，合并成一个板块会把同一份内容重复填进两边；通用问法（工作单位/公司名称/担任职务）仍会先取工作经历、再兜底实习经历。
- **项目经历 约 15 项**：项目名称、团队规模、是否海外、项目职务、实践方式、起止时间、项目地址、项目链接、证明人姓名·联系方式·职位、项目描述、项目职责、项目成果。
- **校园经历**：组织名称、级别、职位、起止时间、工作内容、本人职责。
- **社会实践**：实践单位、实践岗位/身份、起止时间、实践内容。
- **证书 8 项**、**获奖经历（奖学金）8 项**（起止时间只读、奖项级别/奖励类型/奖励等级、获奖描述；「获奖详细描述」类表单项也由获奖描述取值）、**专利 7 项**（发明人、状态）、**论文 11 项**（作者、卷期、影响因子、刊物等级、作者顺序、DOI、链接、摘要）、**外语 7 项**（掌握程度、听说、读写）、**技能特长 6 项**（技术/软件/证书/软技能）、**自我评价 2 项**（自我介绍、自我评价分开两栏，表单问哪个填哪个）、**家庭情况 13 项**（性别、教育程度、身份证号、联系电话、联系地址等）。

- **起止时间**：凡有开始/结束时间的板块，记录内都有一条只读「起止时间」（如 `2024-06 ~ 2024-09`），随两个日期实时刷新，和竞品一致。
- **期望城市**：`tags` 类型，回车/顿号添加、× 删除、最多 5 个，另有「任意城市」勾选；底层仍存成顿号分隔字符串，匹配与填写链路不变。

省/市/区类字段以 `region` 类型存储为「北京市/海淀区」这样的字符串，填写到网页的级联/下拉组件时由 `filler.js` 逐级点选；`lib/rules.js` 为每个新字段补了中文与英文别名，所以这些字段既能被「一键填写」命中，也会出现在「辅助填写」的字段列表里。

## 内嵌 iframe 的网申页面

部分网申系统（北森、大易等）把表单放在 iframe 里：**悬浮球固定常驻在顶层页面**，不会再"跳进"某个内嵌框架（早期版本会把球交给字段最多的 iframe，结果球落在看不见的小窗里，看起来就像"弹不出来"）。点击顶层球发起「一键填写」时，填写指令会广播给该标签页的所有 frame，iframe 内的表单同样会被填上——发起的 frame 显示进度，其余 frame 静默填写并汇总结果。

## 上传简历解析

- 解析覆盖范围：个人信息（含姓名拼音/身高体重/户口性质/血型/英语等级等）、求职意向、教育、**工作经历与实习经历分开解析**、项目、**社会实践**、证书、**获奖/论文/专利/外语/家庭成员**、技能与自我评价。


- 支持 `.pdf` / `.docx` / `.txt` / `.md`（旧版 `.doc` 请另存为 `.docx` 或 PDF）。
- PDF 用内置 pdf.js 本地解析，DOCX 直接解 zip 读取 `word/document.xml`，**全程离线，不上传服务器**。
- 解析规则：按「个人信息 / 求职意向 / 教育背景 / 工作经历 …」等标题分段，识别 `键：值` 字段（一行可含多个键值）、时间段（`2018.09-2022.06`）、学历/院校/专业、公司名与职务拆分等。
- 解析结果会新建一份简历并打开编辑器；识别不到的内容以弹窗提示，请手动核对补充。

## 多份简历 · 按站点记忆复用

- 可为不同单位/岗位准备不同简历（技术岗、综合岗、省考各一份）。
- 在某个网站点击悬浮球面板里的「切换简历」（展开「识别统计与简历」）选定简历后，**该网站会记住你选的简历**（按域名绑定），下次打开同一网站自动复用，不影响其它网站的全局默认简历。
- Popup 简历列表中会显示每份简历「站点记忆」绑定了哪些域名；删除简历时其绑定一并清除。

## 下拉 / 级联等自定义控件

除原生 `<select>` 外，插件还能自动填写现代前端组件库的下拉与级联控件：

- **自定义下拉**（element-ui `.el-select`、ant-design `.ant-select`、通用 `[role=combobox]`）：模拟点击展开 → 在弹出的选项面板中按语义匹配（如「硕士」→「硕士研究生」、「中共党员」）→ 点选。
- **级联选择 / 省市区**（`.el-cascader`、`.ant-cascader`）：把简历地址（如「北京市海淀区学院路30号」）拆成「北京市 → 海淀区」逐级展开点选。
- **兜底**：自定义下拉/级联启发式失败后，若已开启 AI，会进入 DOM Agent 多轮点击；仍失败则把目标值**复制到剪贴板**并标红提示，你点开该控件直接粘贴即可。
- 简历基本信息已支持 `微信号 / QQ号 / 兴趣爱好` 等字段，可在编辑器填写后被自动识别匹配。

## 可选 AI 语义增强

设置中勾选「启用 AI 语义增强」并填写 OpenAI 兼容接口配置（默认 DeepSeek）：
- API 地址：如 `https://api.deepseek.com/v1`。**填到主机端口或带 `/v1` 均可**（如中转站 `http://1.2.3.4:3000`），插件会自动补全 `/v1` 并兼容 New-API / One-API 等中转站；若某路径返回网页会自动回退尝试其它路径。
- API Key：`sk-...`（仅存本机浏览器，请求由扩展后台直连你的服务）
- 模型：如 `deepseek-chat`

规则引擎未识别的字段会批量交给大模型映射；映射结果按字段信号写入本地自学习缓存，下次同信号直接本地命中、不再花 token。解析服务链路（`/api/page/understand`）映射成功时同样写入缓存。
原生下拉/单选的选项对不上简历值时（如「硕士」vs「研究生」vs「硕士研究生学历」），本地同义词归一失败后会把选项列表交给模型挑一个序号（AI 选项兜底），仍失败才标红为「选项里没有匹配项」。
同一套 Key 也用于「AI 辅助点击」（设置里可单独关闭）。若填写了解析服务地址，点击规划会优先走 `/api/page/act`，失败再回退扩展后台直连模型。
不配置 Key 时插件完全离线可用。


## 简历编辑器

编辑器页（参考「来个简历闪填」的 UI 语言重设计）：

- **左侧内容导航**：总览「已填写 X / Y 个字段、完成度、未补齐 N 项」+ 进度条；每个模块一项，含完成度圆环、`已填/总数` 计数与徽标——「未补齐 N 项」（红）/「已完成」（绿）/「尚未新增内容」（灰）；点击模块平滑滚动定位并高亮
- **查看未补齐项**：一键过滤视图——已完成模块整卡隐藏，未填字段琥珀色高亮 + 「未填」标签，已填字段淡显，并自动定位到第一个未补齐项
- 表单卡片右上角同步显示模块补齐状态；边填边统计，输入即时更新完成度
- 顶栏：简历名称 + 保存状态 + 解析导入 / 保存

测试注意：
- CDP 测试会先把标签页带到前台并等页面稳定——**后台标签页的 `setTimeout` 会被浏览器节流到秒级**，自定义下拉/级联的轮询等待会放大数倍，导致断言读到"填写中途"状态；
- 改代码后执行 `node scripts/reload-ext.js <端口>` 再跑测试（扩展 reload 后旧 content script 消息通道失效，测试驱动会自动重载页面）；**若 service worker 处于休眠态会提示未找到，重载页面唤醒后再执行即可**；改动 `content/*.js` 后最稳妥是重启测试浏览器（content script 会被缓存）；
- 各专项脚本会改动当前简历/站点绑定等状态，**建议每跑一个脚本前重启一次测试浏览器**（或至少按 `cdp-test` → `cdp-editor-ui` → `cdp-verify-region-helper` → `cdp-verify-features` 的顺序）；
- `cdp-test.js` / `cdp-verify-features.js` / `cdp-verify-region-helper.js` 需要先启动本地测试服务（`test-server.js`）与带扩展的 Edge。

## 隐私说明

- 简历数据仅存于浏览器本地 `chrome.storage.local`，不上传任何服务器
- 「记录职位」的投递记录与「反馈不适配」的反馈同样只存本机，可在弹窗的「本地记录」中查看/导出/清空
- 悬浮球的纵向位置（沿右边框上下滑动的高度）也仅记录在本地，用于下次打开页面时恢复
- 上传的 PDF / Word / TXT 简历**全程在本地浏览器内解析**（内置 pdf.js），不经过任何网络
- AI 请求只发往你自行配置的接口地址
- 插件不会自动提交任何表单，也不会代替你点击「提交」
